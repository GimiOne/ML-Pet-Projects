# TodoApp - Приложение для управления задачами

TodoApp - это мультиплатформенное приложение для управления задачами, разработанное с использованием Flutter. Приложение позволяет создавать, редактировать и удалять задачи с интуитивно понятным интерфейсом.

## Функциональность приложения

### Основные возможности
- Добавление новых задач через текстовое поле
- Просмотр списка задач с использованием ListView.builder
- Редактирование существующих задач
- Удаление задач
- Отображение времени создания каждой задачи
- Счётчик общего количества задач

### CRUD операции
- **Create** - Создание новой задачи через TextField и кнопку добавления
- **Read** - Отображение списка задач в ListView.builder
- **Update** - Редактирование задачи через inline-режим
- **Delete** - Удаление задачи с подтверждением

### Интерфейс
- Material Design 3
- Адаптивный дизайн
- Карточки для каждой задачи
- Цветовая индикация кнопок действий
- Отображение даты и времени создания

### Технические особенности
- Кроссплатформенность (Android, iOS, Windows, Linux, Web)
- StatefulWidget для управления состоянием
- ListView.builder для эффективного отображения списка
- TextEditingController для работы с текстовым вводом

## Структура проекта

Основные директории и файлы:

- `lib/` - Основной код приложения
  - `main.dart` - Точка входа в приложение, содержит весь код
    - `TodoApp` - StatelessWidget, корневой виджет приложения
    - `TodoScreen` - StatefulWidget, основной экран со списком задач
    - `TodoItem` - Модель данных задачи
- `android/`, `ios/`, `windows/`, `linux/`, `web/` - Платформо-зависимые конфигурации
- `pubspec.yaml` - Зависимости проекта

## Основные компоненты

### TodoScreen (StatefulWidget)
- Управление списком задач
- Обработка текстового ввода
- Режим редактирования задач
- Отображение статистики

### TodoItem (Модель данных)
- `title` - Название задачи
- `createdAt` - Дата и время создания

## Начало работы

1. Клонируйте репозиторий
2. Установите Flutter SDK
3. Выполните `flutter pub get` для установки зависимостей
4. Следуйте инструкциям в [INSTALL.md](INSTALL.md) для настройки окружения

## Сборка приложения

### Android APK
```bash
flutter build apk --release
```

### Windows
```bash
flutter build windows
```

### Web
```bash
flutter build web
```

## Запуск приложения

```bash
flutter run
```

Для запуска на конкретной платформе:
```bash
flutter run -d windows
flutter run -d chrome
flutter run -d android
```
